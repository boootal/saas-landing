Частые вопросы

Это законно?

Мы агрегируем только открытые, слитые и приватные базы, к которым у нас есть лицензионный доступ. Вы получаете уже опубликованные данные. Использование — под вашу ответственность и в рамках 152-ФЗ.

Откуда берутся приватные базы?

Партнёрства с брокерами данных, верификация контрагентов, маркетплейсы и OSINT. Каждая запись имеет источник и дату — вы видите, откуда факт.

Хранятся ли мои запросы?

Нет. Запросы не логируются в открытом виде, отчёты хранятся только в вашем кабинете и удаляются по кнопке. Логи — только хеши для биллинга.

Можно подключить свои базы?

Да, на тарифе Макс — загрузите CSV/БД по API, настроим нормализацию и граф. Вы сами решаете, кому открыть доступ.

Есть ли API для автоматизации?

Да, REST, вебхуки и SDK для Python/Node. До 120 RPS на Макс, 99,9% SLA.
